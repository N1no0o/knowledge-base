# 华为云支持服务立项 · AWS 竞品对标

> 数据基准：AWS 官网 + 官方文档 + 第三方 GA 报道 ｜ 归档 2026-09-21
> 原则：**每条都有官方出处**，可直接引用于立项材料与答辩。

## ① AWS 官方解决方案是什么

**不是一个产品，是三层叠起来的体系：**

| 层 | 产品 | 一句话定位 |
|---|---|---|
| **第 3 层 · AI** | **AWS DevOps Agent**（2026-03 GA） | 随时待命的自主运维队友，自主调查事件、给根因、给缓解方案 |
| **第 2 层 · 服务** | **Incident Detection and Response (IDR)** | "人 + 工具"：IME 全天候值守，**5 分钟响应**，为每个工作负载定制 Runbook |
| **第 1 层 · 数据** | **AWS Health** + EventBridge + PHD | **200+ 服务集成**的事件权威数据源；EventBridge 是**唯一集成点** |

**IDR 接入方式**：EventBridge 直连 / Webhook / SNS 三种通道，告警源为 CloudWatch 或第三方 APM。

## ② 效果如何

| 指标 | AWS 宣称 | 可信度 |
|---|---|---|
| 响应时效 | **IME 5 分钟内**主动响应 | ✅ 官方承诺，写入定价页 |
| 企业级 SLA | 业务/任务关键型停机 **< 30 分钟**；Enterprise **< 15 分钟** | ✅ 官方 |
| **MTTR 降低** | **75%** | ⚠️ **AWS 自报**，preview 期数据，未披露样本量 |
| **根因准确率** | **94%** | ⚠️ **AWS 自报**，未披露方法论 |
| 客户实证 | **WGU：2 小时 → 28 分钟（-77%）**；**Zenchef：1-2 小时 → 20-30 分钟（约 -75%）** | ✅ 官网客户案例，有具名客户 |
| 效果度量 | IDR 提供 **SLO 性能数据** + 事件数量/时长报表 | ✅ 官方文档 |

> **⭐ 最重要的启示**：AWS 所有 AI 效果指标**都收敛到 MTTR 这一个北极星**。
> 我们的效果目标也应**收敛到主指标**（建议：有效告警触达率 + MTTR 缩短比）。

## ③ 定价（本轮补齐的最大空白）

### 三档支持计划

| 计划 | 最低消费 | 定价结构（取大者） |
|---|---|---|
| **Business Support+** | **$29/账户/月** | $29　或　≤$1万部分 **9%**；$1万-8万 **7%**；$8万-25万 **5%**；>$25万 **3%** |
| **Enterprise Support** | **$5,000/月** | $5,000　或　≤$15万 **10%**；$15万-50万 **7%**；$50万-100万 **5%**；>$100万 **3%** |
| **Unified Operations** | **$50,000/月** | $5万　或　≤$100万 **10%**；$100万-500万 **6%**；>$500万 **5%** |

**官方定价示例**：
- 月消费 $2万 → Business Support+ **$1,600**
- 月消费 $75万 → Enterprise Support **$5.2万**
- 月消费 $150万 → Unified Operations **$13万**

### 增值服务

| 服务 | 定价 |
|---|---|
| **Incident Detection and Response** | Enterprise Support 客户**最低 $7,000/月 或 月消费的 2%**（取大者）；**Unified Operations 已包含** |
| **Countdown Premium** | **$10,000/项目/月**（Unified Operations 已包含） |
| **DevOps Agent** | **$0.0083/agent-second**，秒级按量，无预付费，**待机不计费**，2 个月免费试用 |
| **抵扣金捆绑** | DevOps Agent 抵扣金 = 已付支持费的 **30% / 75% / 100%**（对应 Business Support+ / Enterprise / Unified Operations），每月 10 日发放，**月末过期** |

### DevOps Agent 实际成本（第三方测算）

| 场景 | 月成本 |
|---|---|
| 单次调查（5-10 分钟） | **$2.50 ~ $5.00** |
| 复杂事件（连续 1 小时） | **$29.88** |
| 月 20 次事件（各 10 分钟） | **约 $100** |
| 加日常 SRE 任务 | **约 $250** |

### ⚠️ 必须知道的计划变动

| 变动 | 时间 |
|---|---|
| Developer Support / Business Support 停服 | **2027-01-01** |
| Enterprise On-Ramp 退役（自动升级到 Enterprise） | **2027-01-01** |
| Incident Manager 不再对新客户开放 | **2025-11-07** |
| **Enterprise Support 最低消费从 $15,000 降到 $5,000** | 已生效 |

> **⭐ 启示**：AWS 在**主动下沉、降低门槛、把 AI 塞进基础能力**。
> **⇒ "AI 作为差异化"的窗口期约 2 年。**

## 答辩用法

这套数据在立项里有三个直接用法：

1. **论证收费合理性** —— "与 AWS Support Plans 分级模式一致，有行业先例可引用"（B 路径理由④）
2. **确定效果北极星** —— 学 AWS 收敛到 **MTTR**，不要散列一堆指标
3. **判断竞争窗口** —— AWS 已在把 AI 下沉到基础能力，我们做 AI 差异化的窗口期约 2 年
