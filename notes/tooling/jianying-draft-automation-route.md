# 剪映专业版路线细化方案 —— SVIP 加持下的本地闭环自动化

**一句话结论：老板持有剪映 SVIP（关键事实：SVIP 才覆盖电脑端，VIP 仅手机/平板 App），据此把原方案里的路线 B（剪映草稿自动化）从"二期可选"升为**一期主力**。但路线 B 有三条硬约束——剪映锁 6.8、Python 必须 3.11、素材英文路径放 D 盘——任一条不成立，路线 B 直接不成立，不要抱侥幸。**

## 一、SVIP 带来的四个直接增益（这是重做路线 B 的全部理由）

| SVIP 权益 | 对本方案的作用 |
|---|---|
| **全库版权音乐 + 官方商用授权说明** | **直接解除原方案的「音乐版权风险」项**——曲库曲目可放心发布，不必再绕 Pixabay 等外部源 |
| **4K 超清无水印导出** | 保留升级空间；当前 1080P 横屏够用，后续要出 4K 母版不必换工具 |
| **精细人声分离 / AI 字幕等全套高阶 AI** | 处理 Action 5 Pro 风噪现场音的现成手段；旁白字幕可直接用剪映花字渲染，观感远好于 ffmpeg 烧字幕 |
| **1TB 云端素材空间 + 云端批量渲染** | 渲染不吃本机 CPU/GPU；素材可云端存，多端草稿同步 |

## 二、总体分工：Python 管"判断"，剪映管"呈现"

**路线 A 与路线 B 不是二选一，而是接力**——这是整个方案的核心。

| Python 脚本层（免费、可控、可调） | 剪映层（观感、素材、导出） |
|---|---|
| ① 素材导入与收件箱归档 | ⑥ 按清单生成剪映草稿（转场/花字/滤镜/动画、BGM 走 SVIP 曲库、字幕用花字渲染） |
| ② 场景切分（PySceneDetect） | ⑦ UI 自动导出 1920×1080 MP4 |
| ③ 质量筛查（抖/曝/糊/静止） | |
| ④ 节拍计算与切点吸附 | |
| ⑤ 旁白稿生成 + edge-tts 配音 + BGM 侧链闪避混音 | |
| ⇒ 全部免费、无版本约束 | ⇒ 依赖版本锁定（见 §三） |

> 分界逻辑：画面质量筛查、节拍对齐、旁白合成属**判断类**，Python 做最合适（无头、可回归测试、改参数立刻见效）；转场/花字/滤镜/曲库属**呈现类**，手工在剪映里搭成本极高，交给 `pyJianYingDraft` 按代码常量复现，一次投入长期复用。

**子路径**：B1 本地剪映（**一期推荐主力**，素材不出本机、无第三方依赖）vs B2 云端渲染（HDraft，需申请 AuthKey，适合后续批量日更提速）。**一期做 B1**。

## 三、硬约束清单（这三条做不到，路线 B 直接不成立）

### 3.1 剪映版本必须锁 6.8

| 能力 | ≤ 5.9 | 6.0 – 6.8 | ≥ 7.0 |
|---|---|---|---|
| `pyJianYingDraft` 生成草稿 | 支持 | 支持（明文草稿，向后兼容） | 支持 |
| 自动批量导出 | 支持 | **支持（6.8 实测通过）** | **失效**（UI 控件被隐藏） |
| 读取剪映自己保存的草稿当模板 | 支持 | **不支持**（草稿已加密） | 不支持 |

- **🔴 本表修正了上游文档的旧口径**（原写"自动批量导出仅 ≤ 6.0"，实测 **6.8 通过**）。
- **代价**：放弃"在剪映里手工做模板再让脚本套用"的模板模式——转场 ID、字体、滤镜 ID、动画 ID 这些样式常量改为**在 Python 代码里维护**，效果等价且更利于版本管理。
- **必须防范自动更新**：剪映默认自动升级，升到 7.x 后自动导出**静默失效**（不报错，点了没反应），可能白跑一小时才发现。三道兜底：
  1. 装完立即在设置里关闭自动更新（若无此开关 ⇒ 走第 2 条）
  2. 备份剪映可执行目录，被覆盖后从备份还原
  3. **脚本层版本自检**：每次跑导出前读 `JianyingPro.exe` 的 `FileVersion`，主版本号 ≥ 7 直接报错退出。**这条最关键——让失败发生在第 0 秒而不是第 60 分钟**

### 3.2 Python 必须是 3.11

`pyJianYingDraft` 的自动导出依赖 `uiautomation`，该库在 **Python 3.13 下有依赖问题**，官方推荐 3.8 / 3.10 / **3.11**。本机现有的 managed 3.13.12 与系统 3.12.10 **都不在推荐列表**。

- 安装**便携版 Python 3.11** 到 `D:\AI\_tools\python311\`（不写注册表、不动系统 PATH，干净可弃）
- 用它建 venv（`D:\AI\_tools\video-pipeline\.venv311\`），`pyJianYingDraft`、`ffmpeg`、`PySceneDetect`、`librosa`、`edge-tts` 一并装进同一环境，避免两套 Python 的心智负担

### 3.3 素材必须放 D 盘且路径不含中文

剪映导入素材是**引用原路径、不复制进草稿**；`pyJianYingDraft` 对中文路径有已知兼容问题。

- 素材放 `D:\AI\my_project\media\inbox\<YYYY-MM-DD>\`，剪映直接读
- 草稿目录默认 `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`，属剪映自身数据、可接受留 C 盘；**素材必须 D 盘**（占空间的是素材）
- 素材目录、文件名、草稿名、输出路径**一律英文数字**
- 素材移动过位置或换机器 ⇒ 草稿引用失效，**成片没出来先查这个**
- ⚠️ 新建 `media/inbox/` 目录后**需同步登记到知识库扫描白名单**（`.workbuddy` 侧同步机制的既有约束）

## 四、SVIP 会员身份与「导出死循环」风险（务必读）

`pyJianYingDraft` 官方明确警告：*请确认有导出草稿的相关权限（不使用 VIP 功能或已开通 VIP），否则可能陷入死循环。*

- **机制**：草稿引用了会员专属素材（SVIP 曲库音乐、付费字体、蓝钻特效），而剪映客户端**未登录 / 会员过期 / 登录态失效**时，导出会卡在**无提示的等待循环**里——脚本看着"还在跑"，实际永不结束。
- 老板是 SVIP ⇒ 风险天然可控，但要保证三件事：
  1. 剪映专业版**保持登录状态**（别退出）
  2. 会员有效期覆盖整个流水线使用周期（到期前导出会突然卡死，现象极具误导性）
  3. **脚本层加导出超时熔断**：单条草稿导出超过 N 分钟无进展就 kill 进程并报警，不靠人盯 —— 纯工程兜底，无论会员状态都该加

## 五、音乐与字幕策略（SVIP 的直接变现）

- **音乐**：一律从剪映 SVIP 曲库选，由 `pyJianYingDraft` 按曲目 ID 在草稿里引用。附带官方商用授权说明 ⇒ 抖音发布无版权顾虑，且平台曲库曲目在推荐侧有天然亲和度。**原方案「优先平台曲库」的风险项至此完全解除。**
- **旁白字幕**：旁白稿是自己生成的、文本已知，不需要 AI 识别 ⇒ 直接让剪映按文本渲染，用 SVIP 字体 + 花字 + 气泡，观感比 ffmpeg 烧字幕好一个量级。工作量只是在草稿里多加一条文本轨道。
- **风噪现场音**：SVIP「精细人声分离」是剪映**界面内**的 AI 功能，UI 自动化点击不稳定 ⇒ 务实做法是先用 ffmpeg `afftdn` 做一版，观感不够再手动进剪映处理（这一小段允许人工）。

## 七、分阶段落地（在原计划上修订）

**P0 · 环境与最小闭环**
1. 装剪映专业版 6.8，关闭自动更新，登录 SVIP
2. 装 Python 3.11 便携版 + venv + 全部依赖；装 ffmpeg
3. 用仓库 `demo.py` 跑通：生成含视频/音频/文本的草稿 → 剪映里能看到 → 自动导出成 MP4
4. **验收：`demo.py` 产出能导出的草稿，且 `export_draft()` 真的点完了导出。这一步不通，后面全部免谈，先别碰真实素材**

**P1 · 徒步素材全链路**
5. Python 层：素材导入 → 场景切分 → 质量筛查 → 节拍吸附 → 产出片段清单 JSON
6. Python 层：旁白稿生成 + `edge-tts` 配音 + BGM 侧链闪避混音
7. 剪映层：读清单 JSON → 生成草稿（转场/花字/滤镜/SVIP 音乐/字幕）→ 自动导出 1920×1080
8. 验收：5–10 分钟真实素材产出 3–5 分钟横屏成片，无废段、旁白与画面对齐、BGM 有闪避、字幕是剪映花字样式

**P2 · 发布与提效**
9. Playwright 半自动上传创作者中心（自动填标题/话题/封面，人工点发布）
10. 导出超时熔断 + 剪映版本自检 + 会员登录态检查，三个兜底全部落地
11. 可选：视觉模型语义选段；可选：HDraft 云端渲染提速
12. 验收：一条命令从素材文件夹推进到"抖音草稿箱已填好"，人工只剩一次点击

## 八、风险表

| 风险 | 等级 | 应对 |
|---|---|---|
| 剪映被自动更新到 7.x | **高** | 关自动更新 + 备份可执行目录 + **脚本版本自检（主版本 ≥7 直接退出）** |
| SVIP 会员到期导致导出卡死 | 中 | 脚本导出超时熔断；会员到期日前主动提醒 |
| Python 3.13 下 uiautomation 依赖问题 | **高** | 统一用便携版 Python 3.11，不抱侥幸 |
| 模板模式不可用（6.x 草稿加密） | 低 | 样式常量写在 Python 代码里维护，效果等价 |
| 导出期间误触鼠标键盘 | 中 | 导出会抢焦点、移动光标，安排在人不在的时段跑 |
| 素材路径含中文或位置变动 | 中 | 英文路径；移动素材后重新生成草稿 |
| 中文路径在 `pyJianYingDraft` 下的兼容问题 | 中 | 素材目录、草稿名、输出路径全部英文数字 |
