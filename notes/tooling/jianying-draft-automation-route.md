# 剪映路线（当前态 v2）—— 解除版本锁，只剩「导出」这一步必须人工

**一句话结论：原方案「必须把剪映锁在 6.8」的前提已经不成立——社区自维护分支 `aoguai/pyJianYingDraft` 已实现高版本草稿可逆读写（README 在剪映 10.8 逐项打 ✅），所以装官方最新版即可，不用找 6.8 历史包、也不用防自动更新。整条链路现在只剩一个硬边界：剪映 7+ 隐藏了导出控件，自动导出只支持 6 及以下 ⇒ 最新版路线的取舍是「人工点一次导出」换掉三年版本债，这笔账划算。**

## 一、v1 → v2 变了什么（一句话）

v1 的核心约束是「锁 6.8」，理由是原版 `pyJianYingDraft` 读不了 6.0 之后加密的草稿。**该前提已不成立：**

| 事实 | 证据 |
|---|---|
| 分支存在且活跃维护 | `aoguai/pyJianYingDraft`，2026-01-22 建库、最后推送 **2026-10-14**，Apache-2.0 |
| 核心功能在 **剪映 10.8** 验证通过 | README 功能矩阵逐项标注 10.8 ✅ |
| 加密草稿可逆读写 | 借本机 `videoeditor.dll` 加解密，**不分发该 DLL**；参考实现在 **10.3.0 ~ 10.6.5** 验证 |
| 提示词里可直接引用 **SVIP 云端曲库** | `draft.CloudMusicMaterial(...)` 按曲目 id 引用，新版 ✅ |

> 来源：`https://github.com/aoguai/pyJianYingDraft` README（2026-10-17 拉取）。

## 二、唯一硬边界：导出（必须说死）

自动导出依赖 `uiautomation` 模拟点击剪映的导出控件。**剪映 7+ 把这些控件隐藏了** ⇒ 自动导出**只支持 6 及以下**：5.9 与 6.8 实测通过，**10.8 明确 ❌**（打开草稿 ❌ / 导出 ❌ / 调分辨率帧率 ❌）。

这是一道取舍，没有两全：

| | 用最新版剪映（10.x，**已选**） | 锁 6.8（老板已否决） |
|---|---|---|
| 草稿可编程 | ✅ | ✅ |
| 转场/滤镜/花字/关键帧/云端曲库 | ✅ 全部支持 | ✅ |
| **自动导出（无人值守）** | ❌ **必须人工点一次** | ✅ |
| 软件版本 | 最新、功能完整 | 2023 年老版本 |
| 要防自动升级 | 不用 | 必须（升到 7 就静默失效） |

**判断依据**：自动导出省下的只是「一次点击」，代价是把整个软件退回三年前并长期防升级 ⇒ 不划算，走最新版。

## 三、修正后的完整链路（人工 ≈ 3 分钟）

```
【手】拔卡插读卡器
   ↓
【自动】归档 + 校验 + 解析 Action 5 Pro 的 SRT（GPS/海拔/时间戳）
   ↓
【自动】场景切分 · 质量筛查（抖/曝/糊/静止）· 按海拔曲线挑高光
   ↓
【自动】LLM 写旁白稿 → edge-tts 配音 → 按旁白时长反推每个剪点
   ↓
【自动】生成剪映草稿 draft_info.json
       视频轨：切片 + 转场 + 滤镜
       音频轨：旁白 + SVIP 云端曲库 BGM + 音量关键帧（人声处闪避）
       文本轨：旁白字幕，花字样式
   ↓
【手】打开剪映 → 看一眼 → 点「导出」（约 30 秒）
   ↓
【手】点「发布到抖音」
```

**人工成本 = 插一次卡 + 点导出 + 点发布**；剪片、配乐、写稿、配音、上字幕、排版全部自动。

## 四、能力矩阵（只列本方案用到的）

**✅ 新版剪映 10.8 可用**：本地视频/时间控制/截取/变速/整体调节；**转场**、片段动画、滤镜、画面特效、混合模式、背景填充；文本与样式、**花字**、气泡、逐字富文本、描边阴影、`.srt` 批量导入、文本动画；本地音频、淡入淡出、音量关键帧、**云端曲库音乐**、音色效果；平移/旋转/缩放/饱和度/alpha 关键帧；贴纸与贴纸关键帧。

**🟡 有坑不影响主线**

| 项 | 说明 | 应对 |
|---|---|---|
| 视频蒙版 | 新版未验证，上游报不生效 | 主线不用蒙版 |
| 字体 | 未缓存字体需二次打开草稿才生效 | 用剪映内置字体，或走 fork 的「本机字体路径」写入 |
| 轨道顺序 | 从**其它草稿导入**的轨道可能错序 | 不用模板导入模式，全部脚本自建轨道 |
| 加密 codec | 仅在 10.3~10.6.5 验证，10.8 未明确保证 | **见 §七 的 P0 验证点** |
| 特效缓存 | 打开草稿时可能「xx 加载失败」 | 首次打开联网让剪映下缓存，二次打开即好 |

**❌ 明确不可用**：曲线变速 · 特效/滤镜**参数**的关键帧 · 新版下的自动导出。

## 五、v1 仍然有效的约束（别一起丢掉）

1. **Python 必须 3.11**：`pyJianYingDraft` 的导出依赖 `uiautomation`，在 **3.13 下有依赖问题**，官方推荐 3.8/3.10/**3.11**；本机 managed 3.13.12 与系统 3.12.10 都不在列表 ⇒ 用便携版到 `D:\AI\_tools\python311\`，venv 在 `D:\AI\_tools\video-pipeline\.venv311\`。
2. **素材必须 D 盘、路径不含中文**：剪映导入是**引用原路径、不复制**；`pyJianYingDraft` 对中文路径有已知兼容问题 ⇒ 素材 `D:\AI\my_project\media\inbox\<YYYY-MM-DD>\`，目录/文件名/草稿名/输出路径一律英文数字。素材移动或换机 ⇒ 草稿引用失效，**成片没出来先查这个**。
3. **SVIP 覆盖电脑端**（VIP 仅手机/平板）⇒ 路线 B 的前提成立。
4. **「导出死循环」风险仍在**：草稿引用会员专属素材（曲库音乐/付费字体/蓝钻特效）而客户端未登录、会员过期或登录态失效时，导出会卡在**无提示的等待循环**（脚本看着在跑、永不结束）。三条防护：保持登录 / 会员有效期覆盖整个周期 / **脚本层导出超时熔断**（超过 N 分钟无进展就 kill 并报警）——第三条是纯工程兜底，无论会员状态都该加。
5. **分工铁律**：路线 A 与 B 不是二选一而是**接力**——Python 管「判断」（切分/筛查/节拍/旁白/混音），剪映管「呈现」（转场/花字/滤镜/曲库/导出）。画面质量筛查与节拍对齐用 Python 最合适（无头、可回归、改参数立刻见效）。

## 六、SVIP 在本方案里的四处变现

| SVIP 权益 | 链路里的用法 |
|---|---|
| **云端曲库 + 商用授权** | 草稿按曲目 id 引用，抖音发布无版权顾虑 ⇒ 直接消掉 v1 的「音乐版权风险」 |
| **花字 / 商用字体** | 字幕轨直接用花字渲染，观感远好于 ffmpeg 烧字幕 |
| **4K 无水印导出** | 当前 1080P 够用，留出 4K 母版余地 |
| **音色克隆**（录 5 秒样本） | 旁白可换成老板自己的声音，**本方案最值得试的一项** |

**旁白两条路：一期先用 A**

| | A · edge-tts（免费，**一期**） | B · 剪映音色克隆（SVIP） |
|---|---|---|
| 做法 | 脚本合成 mp3 塞进音频轨 | 剪映内克隆 → 生成配音 → 脚本按音频时长对齐 |
| 声音 | 微软神经音色（云健/云希），专业但「播音腔」 | 老板自己的声音 |
| 自动化 | 全自动、时长可精确读取 | 克隆与合成在界面内，需人工一轮 |
| 建议 | 先把链路跑通 | 链路稳定后换，观感上限更高 |

> 关键工程点：**剪辑顺序由旁白音频驱动**——先定旁白时长，再反推每段画面多长，而不是先剪画面再硬塞旁白。这是「像样」与「业余」的分水岭。

## 七、P0：只验一件事

> **脚本生成的草稿，最新版剪映（10.8/11.x）能不能正常打开？**

README 只把加密 codec 的验证范围写在 10.3~10.6.5，10.8 是「功能支持但 codec 未明确保证」。这一步不通，整条剪映路线就得换降级方案。

**最小验证（预计 1 小时内出结果）**
1. 装官方最新版剪映（**GUI 安装**、自选 D 盘；官方包是 2.8 MB 的 NSIS 引导器，`/S` 静默无效，见 §九）
2. 装 Python 3.11 便携版 → `D:\AI\_tools\python311\`
3. 建 venv，`pip install pyJianYingDraft`（走 aliyun 镜像）
4. 跑 20 行脚本：建 1920×1080 草稿 → 加视频片段 + 文本 + 音频 → `save()`
5. **打开剪映，看草稿箱里有没有它、双击能不能正常播放**

判据：✅ 能打开 ⇒ 路线成立，进 P1 搭真实链路；❌ 打不开/报错 ⇒ 走 §八 降级。

## 八、降级方案（P0 失败时）

| 方案 | 做法 | 代价 |
|---|---|---|
| **D1 · ffmpeg 全自动 + 剪映纯包装** | ffmpeg 出完整成片（切片/混音/烧字幕），剪映只加转场和音乐 | 观感中等，但**全自动、零版本风险** |
| **D2 · 锁 6.8** | 退回老版本换自动导出 | 老板已否决，仅作兜底 |
| **D3 · 纯 GUI 自动化** | 豆包虚拟桌面 / Playwright+UIA 点剪映 | 版本一更新就废，不建议 |

## 九、安装实测结论与叫停记录（2026-10-17，恢复安装时直接看这段）

**剪映官方安装包实测（最省时间的一条）**
1. 官网 `capcut.cn`「立即下载」→ `download-guidance?download_url=...` → 最终直链 `https://lf3-package.vlabstatic.com/obj/faceu-packages/installer/jianying_jianyingpro_0_1.2.46_installer.exe`

**恢复安装最短路径**：① GUI 装官方安装包到 D 盘 → 迁数据目录 + junction；② Python 3.11 embeddable 便携版（python.org 直连 11.5 MB/s）+ aliyun 镜像装依赖；③ ffmpeg 走 `ghfast.top` 代理 BtbN 构建（473 KB/s；npm 镜像只有 2018 年老包，直连 26–38 KB/s 不可取）；④ 用 ffmpeg 合成素材验证「草稿生成」链路。
